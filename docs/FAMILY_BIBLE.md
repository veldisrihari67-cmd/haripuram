# FAMILY BIBLE
# HARIPURAM
## Mark-1 Canon

Version: 1.0

Status: Canon

This document defines all family systems within Haripuram.

Its purpose is:

1. Teach Telugu relationships naturally.
2. Create a living social world.
3. Support language learning through real people.
4. Preserve traditional Telugu kinship terminology.

In Haripuram, relationships are never taught as definitions.

Relationships are taught through people.

---

# Core Principle

Most language-learning systems teach:

Father = తండ్రి

Mother = తల్లి

Brother = అన్న

This system fails.

Haripuram teaches:

Lakshmaiah is Pandu's father.

Anasuya is Pandu's mother.

Narayana is Pandu's grandfather.

Because people are remembered more easily than definitions.

---

# The Root Family

The entire Haripuram learning experience revolves around one extended family.

The learner enters the world as:

## Srihari

Nickname:

## Pandu

Pandu is not merely a character.

Pandu is the learner's representative inside Haripuram.

Whenever Pandu learns, the user learns.

Whenever Pandu encounters a relationship, the user encounters the relationship.
